Chromebook setup

Start JayAI from Linux Terminal with the API key available only in that terminal session. Replace the model only if you have access to it.

cd ~/JayAI-CrossDevice-0.25.0
read -s -p 'OpenAI API key: ' JAYAI_MUSIC_API_KEY; echo
export JAYAI_MUSIC_API_KEY
export JAYAI_MUSIC_MODEL=gpt-4.1-mini
./scripts/start-jayai.sh

Get an API key from your OpenAI developer account. ChatGPT subscriptions and API billing are separate. Do not paste the key into the song brief or lyrics.
